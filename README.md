# fengbinghui.github.io

个人作品集站点（纯 HTML / CSS / JS，零依赖、零构建）。

- 在线访问：<https://fengbinghui.github.io>
- 内容：个人介绍、代表项目（feiyu-ai / OISYS / CommHeatManage）、技术栈、工程实践、编程轨迹
- 特性：深浅色主题、响应式布局、滚动渐入动画、无外部 CDN 依赖

## 本地预览

```bash
# 任选其一
start index.html            # Windows 直接打开
python -m http.server 8080  # 或起一个本地静态服务器
```

## 结构

```text
.
├─ index.html          # 页面结构
├─ assets/
│  ├─ style.css        # 设计令牌 + 布局 + 响应式
│  ├─ main.js          # 主题切换 / 滚动动画 / 计数
│  └─ favicon.svg      # 站点图标
└─ README.md
```
